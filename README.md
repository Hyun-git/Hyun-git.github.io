## Repository Structure

- `_posts/` : Contains all my blog posts written in Markdown format.
- `projects/` : Detailed documentation of the projects I've worked on (e.g., Farmeme, Twotoo).
- `assets/` : Static files including images, stylesheets, and architecture diagrams.
- `_config.yml` : The main Jekyll configuration file.
- `index.md`, `about.md`, `resume.md`, `study.md` : Main pages of the blog.

## Theme

This blog is built upon the [no-style-please](https://github.com/riggraz/no-style-please) theme, a fast, minimalist, and nearly no-CSS Jekyll theme, customized to fit my portfolio's requirements.

## Local Development

To run this blog locally on your machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Hyun-git/Hyun-git.github.io.git
   cd Hyun-git.github.io
   ```

2. Install the necessary Ruby gems:
   ```bash
   bundle install
   ```

3. Start the Jekyll local server:
   ```bash
   bundle exec jekyll serve
   ```

4. Open your browser and navigate to `http://localhost:4000`.
